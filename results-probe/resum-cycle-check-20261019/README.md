# ReSuM's ALL score: released code against its definition, on cyclic patterns

**Kind: probe.** Development machine (see `meta.json`), result sets only; run times are not measurements.

ReSuM's ALL score (Preti et al., EDBT 2018) is the MNI support over the appearances whose edges all weigh more than
the relevance threshold. The released code (commit `38307b2`, built by `tools/build_resum.py`) records, for a pattern
vertex matched with several already matched neighbours, one data edge for all of its pattern edges
(`Util.getIntersection` returns the edge of the first neighbour, `DFSSearch.searchExistances` assigns it to every
constraining neighbour), so the weight of an edge that closes a cycle is not tested. It also tests the ALL condition
on the first embedding found from each root vertex (`DFSSearch.java`, lines 210 and 239).

- `run.sh` (from the repository root) runs both parts below; `random_graphs.py` generates the random graphs.
- **Running example** (`datasets/example.lg`, minSup 2): at tau_w = 5 the released code returns four patterns, the
  ALL definition three; the extra one is the triangle A-B-C, whose edge A-C weighs 2 or 1 in its two occurrences, so
  it is not an ALL pattern and not a WeLT pattern either (`example/resum_vs_definition.csv`,
  `example/resum_within_welt.csv`). At tau_w = 7 both sets are empty.
- **Seeded random graphs** (150 graphs, `random.Random(i)`, 6 to 12 vertices, 3 labels, integer weights 1 to 10;
  minSup 1 and 2, tau_w = 5; `random/summary.csv`): 277 of 300 cells compared (the other 23, all at minSup 1,
  exceeded the 60 s limit of ReSuM); the ALL definition is non-empty in 275. The released code reports patterns that
  are not ALL patterns in 134 cells (8204 patterns, all cyclic), and misses ALL patterns in 6 cells (22 patterns).
  `random/rg139` (smallest graph with extra patterns) and `random/rg141` (a graph with missing patterns) are kept in
  full; the other graphs are regenerated by `random_graphs.py`.

The ALL score is computed exactly in the campaign by GraMi on the graph of the edges weighing at least tau_w (step
`allexact`); the released code is used in probes only.
